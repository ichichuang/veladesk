# Veladesk UX 审计报告（2026-11-11）

- 基线：`main` @ `4e35e7f`（t81 已交付），生产构建（`next build` + `apps/web/scripts/e2e-standalone-server.mjs`），Chromium 156（headless，Playwright 1.64）。
- 方法：真实浏览器操作（点击、右键、滚轮、键盘、拖拽、真实 CDP 触摸事件、文件上传、断网路由拦截），每个结论均有可复现的操作与截图/测量数据支撑。探测脚本见 `artifacts/ux-audit/probes/`，截图见 `artifacts/ux-audit/shots/`。
- 覆盖视口：PC 1440×900、1920×1080、1280×720；手机 390×844、375×667（`hasTouch`+`isMobile`）；深色/浅色各一遍，`prefers-reduced-motion: reduce` 一遍（PC + 手机）。
- 日期说明：测试跨 11-11 23:00 至 11-12 00:20（时钟截图中日期随之变化）。

## 总体结论

**整体体验：7 / 10。** 骨架和交互质感很好：分区胶囊（点击/滚轮/30 个分区自动跟随滚动）、⌘K 命令面板、磁贴拖拽/缩放/撤销、深浅色与壁纸切换、自定义滚动条淡入淡出、键盘 Tab 顺序与焦点可见性、移动端滑动切分区，全部实测可用且对比度达标（正文文字 12.9–14.5:1）。但有两个会直接破坏核心功能可信度的 P1 缺陷（**文件夹浮层内容堆叠错误**、**自定义壁纸保存后黑屏**），加上 ⌘K 快捷键实际无效、网址输入几乎不校验，拉开了与"顺手桌面"目标的距离。移动端是干净的只读 shell，但没有编辑能力。

**最影响体验的 5 个问题：**
1. 文件夹浮层里所有子应用磁贴堆叠在同一坐标，只显示一个，视觉上还把背后分区磁贴透出成"假内容"（P1，功能视觉双缺陷）。
2. 自定义背景上传保存后，桌面壁纸变黑屏并出现破图图标，上传的图片根本没显示出来（P1 功能缺陷）。
3. 搜索框明示 ⌘K，但 Ctrl/Cmd+K 快捷键无效，只能鼠标点击打开（P2 功能缺陷）。
4. 添加应用的网址框不做格式校验：`not-a-url` 存成 `https://not-a-url/`，中文名被转成 punycode 域名，点击即打开失败页（P2 功能缺陷）。
5. 磁贴按钮带 `aria-disabled="true"` 却可点击、可回车打开——读屏用户被告知"禁用"（P2 可访问性）。

## PC 小结

PC 端是完成度最高的主战场：信息架构（时钟/搜索/网格/胶囊/Dock）清晰，动效克制且可被 `prefers-reduced-motion` 关闭（实测 transition-duration=0s）；键盘层（Tab 顺序、焦点环 2px、Esc 逐层关闭、←/→ 切分区）完整；右键菜单体系（桌面/磁贴/胶囊）功能齐全；删除/分区管理等破坏性操作均有确认。扣分集中在：文件夹浮层（P1）、自定义壁纸（P1）、⌘K 失效（P2）、网址校验（P2）与添加/编辑表单不一致（P2）。

## 手机小结

移动端是纯浏览 shell：头部（工作区名/搜索/菜单）+ 横向标签页 + 分区滑动条 + 底部 Dock。实测全部触控目标 ≥44×44px（无违例）；CDP 真实触摸的滑动方向符合惯例（左滑下一分区、右滑上一分区）、长内容竖向滚动无冲突（scrollTop 0→165）、磁贴轻点正常新标签打开、375×667 与 390×844 布局均无破版。主要短板是零编辑能力（UX-12）与浅色模式下卡片对比弱（UX-10）。未能验证真实软键盘弹出（环境限制，见下）。

## 测过且没有问题的部分

- **首次启动**：空数据 → onboarding（视觉/文案清晰）；「一键体验示例工作区」→ 直达桌面；boot 到首屏 ≈0.3–1s（本地，非指标承诺）。
- **分区胶囊**：点击切换、悬停竖向滚轮逐格切换（t81 行为在位）、长分区名截断省略、30 个分区时滚动条溢出可由滚轮逐格推进并自动跟随活动项（scrollLeft 0→888）、水平 deltaX 滚轮可平移。
- **时钟**：HH:MM:SS 翻轮正常走秒（reel transform 实测变化），日期/星期显示正确。
- **⌘K 命令面板（点击路径）**：默认 24 项、搜 "git" 命中 GitHub、Enter 新标签打开、Esc 关闭、底部快捷键提示齐全。
- **磁贴**：点击新标签打开链接；右键菜单（打开/编辑/编辑外观/移到分区/固定到程序坞/删除）；添加应用空名称内联报错「请输入名称。」；编辑改名/改址生效；删除有确认对话框（取消/删除应用）；Dock 固定/移除即时生效（3↔4 项实测）；Dock tooltip「打开 GitHub」/悬停放大。
- **整理模式**：进入/退出（退出整理）、网格拖拽吸附（实测位移 230,115px 对齐）、Ctrl+Z 撤销精确还原、8 向缩放手柄拖拽 99→214px、Ctrl+Z 还原尺寸、工具栏（网格/自由、间距 16px stepper、撤销/重做）、自由排列拖拽可落非整格位置；网格排列/自由排列 radio 单选正确（aria-checked 正确，勾选显示唯一）。
- **分区管理**：新建（默认名「新分区」）、重命名、上移/下移排序、设为默认分区（刷新后仍生效）、删除分区有确认；默认分区不提供删除入口（合理）；分区背景设置入口存在（未深入验证每种预设，见未测）。
- **设置**：主题深/浅色保存生效且取消可回滚；强调色 10 swatch 生效（`--vd-accent` oklch 实变）；界面风格 清爽/柔和/玻璃 切换材质 attr 变化；内置壁纸 极光/午夜/晨曦/薄雾 保存后生效；布局 tab（默认分区、以查看模式启动、网格间距）与通用 tab（界面语言、动效实验、导入/导出、内嵌壁纸、版本 1.0.0）控件齐全。
- **JSON 导入**：粘贴非法 JSON → 内联错误含具体解析位置；合法但格式不符 → 三条明确校验错误（`format 必须是 "veladesk-import"` 等）；上传/粘贴双入口、24 MiB 上限提示、导入前预览的流程文案清楚。
- **滚动**：自定义 OverlayScrollbars 滚动条滚轮后出现（opacity 1）、闲置 2.5s 后淡出（opacity 0）；长分区（44 应用）纵向滚动正常。
- **离线**：启动时 API 不可达 → 恢复后刷新即可正常进入；会话中断网 → 本地编辑仍生效 + 离线徽标（徽标本身见 UX-11）；菜单出现「立即同步」。
- **可访问性**：Tab 顺序合理（搜索框 → 分区 → 磁贴按序 → Dock）；焦点环 2px 可见；Esc 逐层关闭（面板/菜单/对话框/浮层均实测）；所有按钮均有可读名称（无未标注 icon 按钮）；正文对比度 12.88–14.46:1、时钟日期 6.99:1（均超 WCAG AA）；`prefers-reduced-motion` 下分区切换 transition-duration=0s。
- **手机端**：见上文小结；44×44 头部按钮带 `aria-label`（搜索/菜单）。
- **多视口**：1440/1920/1280 桌面布局均无破版，磁贴尺寸随视口 fluid（86–138px 实测）。

## 因环境限制未能测试的部分

1. **真实移动设备与真实软键盘**：仅能以 `hasTouch`+`isMobile`+视口收缩（844→500px）模拟；无法验证真实软键盘弹出/收起时的视口行为与原生滚动惯性、`touch-action` 细节。
2. **读屏器实际朗读**：仅做了 DOM/ARIA 层检查（发现 UX-05），未跑 NVDA/VoiceOver。
3. **性能量化**：未测 FPS/内存曲线；44 应用与 30 分区仅验证功能可用（headless 无 GPU，数据不代表真机）。
4. **上传边界**：未测 24 MiB 上限临界值、非图片文件、超大尺寸图片（部分因 UX-02 已阻断正常渲染路径）。
5. **文件夹的创建路径**（拖 A 到 B 上成组）未测——自建/示例工作区的文件夹**展示**已覆盖并发现 UX-01，创建手势因 arrange 拖拽合组流程复杂未走通。
6. **深浅色"跟随系统"**：`emulateMedia` 无法驱动该应用的显式存储偏好（应用不跟随系统，这本身是设计而非缺陷），只测了显式深/浅。
7. **录屏级帧序列**：过渡动画以连续截图（mid/settled）替代，未输出视频帧。
8. **多标签页同步**：两个标签同时编辑同一工作区的冲突合并未测。

## 主观建议（推测性，未全部实测验证）

- UX-07 的两种生效模式建议统一为"草稿+保存"，与现有 保存/取消 按钮语义一致；壁纸类重资源变更尤其适合草稿式。
- UX-09 若不想做删除撤销，至少在 toast 里告知"已从分区 X 删除"以形成反馈闭环。
