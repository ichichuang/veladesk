# Vela Dawn · Phase 1 动效规格（动画师）

> 2026-11-09 · 依据 CONCEPT.md（2271032）第 2、3、5 节与现有 `apps/web/components/vd/motion-tokens.ts`。
> 状态：规格稿，未实现、未评审。实现与集成归工程。

## 0. 总则
- 总监定稿（2026-11-09）：Dawn 与 FLIP 重排进 P1 正式实现；Orbits 与 Wake 在 P1 做可体验原型，统一放在实验开关 `experimental.helmMotion` 后面，默认关闭。
- 只动 `transform` / `opacity`（光迹用 canvas 或 SVG stroke-dashoffset，不触发布局）。
- 沿用现有语言：主缓动 `power2.out`，不回弹不过冲；拖拽、缩放手势、落点吸附保持直接跟手，不加时长。
- 引擎分工：GSAP 负责 Dawn、Orbits、Wake；Motion 负责卡片 FLIP 重排和组件状态。同一元素只归一个引擎，元素上标注 `data-motion-owner="gsap|motion"`，便于排查。
- 可打断：新交互开始先 kill 或反转当前动画，从当前视觉值接续，绝不跳回起点、绝不排队。
- 所有数值都放进 `packages/ui` 的令牌，组件里不写字面量。

## 1. 新增令牌（秒，GSAP 单位；Motion 侧换算为毫秒或 spring）
| 令牌 | 值 | 用途 |
|---|---|---|
| `dawn.horizon` | 0.18 | 地平线光带上扬 |
| `dawn.reveal` | 0.22 | 内容层显现（与光带重叠） |
| `dawn.stagger` | 0.012 | 磁贴错峰，总错峰时长 ≤ 0.08 |
| `dawn.total`（预算） | ≤ 0.30 | 开屏总时长硬上限 |
| `orbit.pull` | 0.42 | 拉远或推近一个层级 |
| `orbit.travel` | 0.55 | 沿轨道切换空间 |
| `orbit.parallax` | 0.06 / 0.12 / 0.2 | 前、中、后景视差系数（非时长） |
| `wake.fade` | 0.45 | 光迹淡出寿命 |
| `wake.maxPoints` | 24 | 轨迹点上限（非时长） |
| `flip.reorder` | spring：stiffness 520、damping 44、mass 1（临界阻尼，无过冲） | Motion 布局重排 |
| `flip.launch` | 0.26 | 磁贴放大成「帆」再交给浏览器 |
| `ease.standard` | `power2.out` | 沿用 |
| `ease.travel` | `power3.inOut` | 只用于 Orbits 镜头移动 |
| `ease.exit` | `power2.in` | 退场 |

## 2. Dawn 开场（GSAP，签名时刻）
1. 首帧：本地缓存直接绘出完整桌面（opacity 1），动画只是叠加层，不阻塞可交互。
2. 0–180ms：底部一条地平线光带（强调色令牌，低不透明度）由 `scaleY 0→1`、`y 8px→0` 上扬，同时整张画面的亮度遮罩从 0.6 退到 0。
3. 60–280ms：磁贴层 `opacity 0.0→1`、`y 6px→0`，按与地平线距离错峰（每格 12ms，总错峰 ≤ 80ms）。
4. 280–300ms：光带淡出，结束。
- 可打断：用户在动画期间任何指针、键盘、滚轮输入都立刻 `progress(1)`，⌘K 永远不等。
- 只在新标签页冷打开时播放；同会话 5 秒内再次打开，或页面从 bfcache 恢复时，直接静态呈现。
- 减弱动态：不播放光带和位移，只做 120ms 的 opacity 0.85→1，或直接静态。
- 首次使用的引导（磁贴像升帆依次立起）属于 P1 可选项，单独开关，不进 300ms 预算。

## 3. 卡片 FLIP 重排（Motion）
- 拖动中：被拖卡片 1:1 跟手（无时长），`scale 1.03`、阴影提升一级；邻近卡片用 `flip.reorder` spring 让位。
- 落点：被拖卡片用同一个 spring 吸附到格子；落点涟漪是一圈 220ms 的 opacity 0.35→0、scale 0.9→1.15 的描边，只在落点放一次。
- 打开文件夹：用 `layoutId` 让磁贴变形成面板，时长 `popup`（0.24）；关闭时反向。
- 可打断：重排中再拖动，Motion 从当前位置接续；快速连续重排只保留最后的目标。
- 减弱动态：重排瞬时换位，配一个 120ms 的 opacity 交叉淡化；不出涟漪；拖拽本身照常跟手。

## 4. 启航（P1 第一版，GSAP Flip）
- 点击磁贴：磁贴图标以 `flip.launch` 放大到视口约 30%，同时 opacity 1→0，结束后交给浏览器导航。导航不等动画：click 时就开始，动画只是视觉过渡。
- ⌘/中键点击（新标签打开）不做放大，只给 `hoverPress` 的按下反馈。
- 减弱动态：只有按下反馈。

## 5. Orbits 穿梭（P1 只做规格与原型，完整版在 P2）
- 触发：触控板捏合或 ⌘+滚轮向外拉；Esc 或推近返回。连续手势按进度驱动时间线（scrub），松手后按速度方向吸附到最近层级，用 `orbit.pull`。
- 层级：磁贴 → 桌面 → 轨道。拉远时桌面 `scale 1→0.62`，其他空间沿环进入视野，前、中、后三层按 `orbit.parallax` 视差。
- 切换空间：镜头沿环滑动，`orbit.travel` + `ease.travel`；壁纸交叉淡化沿用现有行为。
- 可打断：旅行中反向手势会反转时间线；新目标出现时从当前进度 tween 过去，不回原点。
- 与 Lenis 的冲突：处于 Orbits 视图时，暂停所有容器上的 Lenis；回到桌面再恢复。
- 减弱动态：不做缩放和视差，切换空间直接替换，配 120ms 交叉淡化；轨道视图改为静态的空间列表。

## 6. Wake 光迹（P1 只做原型，默认关闭）
- 一个全屏 canvas 叠加层，`pointer-events: none`。记录最近 `wake.maxPoints` 个指针点，画渐细的线，颜色取强调色令牌、发光强度取主题令牌，每点寿命 `wake.fade`。
- 只在两个场合出现：拖动卡片，以及 Orbits 旅行时跟随镜头。普通指针移动默认不出（遵守「每个空间至多一个主签名」），可在设置里打开。
- 性能：帧预算 2ms，超出就丢点；页面不可见或指针静止 500ms 后停 rAF。
- 减弱动态：完全关闭。

## 7. 验收要点（给实现方自查）
- 开屏从首帧到结束 ≤ 300ms，期间输入立即生效。
- 任一动画中途接到新输入，不出现跳帧或回到起点。
- `prefers-reduced-motion: reduce` 下逐项符合上面的降级。
- 代码里不出现时长或缓动字面量，全部取自 `packages/ui` 令牌。
