# VelaDesk · The Helm — Phase 1 视觉方向与令牌草案

> 2026-11-09 · 视觉设计师 → 总监·Veladesk 拍板 · 依据 `docs/redesign/CONCEPT.md`（2271032）第 2 节原则
> 硬性规则见 visual-designer/PREFERENCES.md 四条；组件库 HeroUI v3；令牌唯一来源 `packages/ui`（现有 `--vdu-*` 在 apps/web/app/globals.css、vd-ui.css，迁移时按下表语义名映射）。

## 三套方向

### A. 拂晓海图 Dawn Chart（推荐）
- 方向：深海墨蓝底，海平线处一道拂晓渐变（杏橙到玫瑰到冷蓝），磁贴是半透明磨砂玻璃，背景叠一层极细的海图经纬线。
- 原因：直接承接 Vela Dawn 开场与「船 / 帆 / 海图」叙事，暖光在深底上记忆点最强；同类起始页大多是纯黑开发者风或壁纸加白卡片，这套一眼可辨。
- 视觉元素：唯一主光源是海平线（开场从这里亮起）；强调色取拂晓杏橙；玻璃磁贴内描一条 1px 高光；经纬线 4% 不透明度，只在拉远时变清晰；Wake 光迹取强调色到透明。
- 明暗：暗色为主场景；亮色版是「白昼海图」，底色为雾白，海平线变成淡金色带，玻璃改为实底轻阴影。

### B. 午夜舵台 Night Helm
- 方向：近黑仪表台，青色磷光强调，像精密航海仪表，参考 Linear / Vercel 的克制精度。
- 原因：开发者和自托管用户接受度最高，最容易做精，性能负担最小。
- 视觉元素：小圆角、低模糊、发丝线分隔；磁贴为实底；发光只用在焦点、指针光迹和刻度上；数字一律等宽。
- 风险：好看但不够新，和市面上的开发者工具撞脸。

### C. 雾帆 Mist Sail
- 方向：亮色优先，雾面纸质与大块柔和色域，高模糊、大圆角，像清晨薄雾里的帆。
- 原因：对受够导航站广告的中文普通用户最友好，最「体面」，截图分享好看。
- 视觉元素：粉雾蓝、浅沙、薄荷低饱和三色域缓慢漂移；磁贴为厚磨砂，柔和投影；文字层级靠字重，不靠颜色。
- 风险：在深色系统下表现弱，Wake 光迹在亮底上不够亮。

**推荐 A**：唯一同时满足「一眼想装」的记忆点和品牌叙事的方案；B 的精度规则（等宽数字、发丝线、焦点发光）并入 A 作为细节层；C 的雾面材质作为 A 的「柔和」材质档保留。

## 规范要点（磁贴、字体、图标）
- 磁贴：1×1 基准 96px，间距 16px，尺寸体系 1×1 / 2×1 / 2×2 / 4×2；图标 48px 居中，标签 13px 单行省略；悬停只抬 2px 加 hairline 变 highlight，不放大。
- 图标：统一 1.5px 线宽线性图标；站点 favicon 放在 surface 圆角底板上，保证杂色 favicon 也整齐。
- 对比度：正文 ≥ 7:1，次要 ≥ 4.5:1，玻璃上的文字以最亮壁纸为准测；壁纸过亮时自动加 6% bg.deep 罩层。
- 活场景情绪板（P1 只出情绪板）：极光、午夜、晨曦、薄雾，分别对应 A 暗、B、A 主场景、C。
